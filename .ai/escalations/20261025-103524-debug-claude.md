**Root cause.** `_emit` (`race_items.gd:339-360`) sets `direction` from `_fire_direction()`, which is flat. It then moves `origin` to the elevated deck nozzle. `_target()` finds no rival at fire time, so `aim_target` is -1 and the convergence branch at lines 352-356 is skipped. The rocket therefore flies level at nozzle height, which is above the `car+0.35` plane. A rival placed on that plane afterward sits below the ray. `_tick_shots(0.6)` casts one `_ray(start, end)` over about 63 m, and it passes over the rival's collider.

Control cases pass because a target exists at fire time, so the aim vector points at `car+0.35`. I could not confirm the rival's collider top height or the nozzle height; the patch doesn't depend on either value.

**Fix.** Give an unaimed rocket a short downward pitch so it reaches the original `car+0.35` plane about `SETTLE` metres out. Record that plane's y on the shot. In `_tick_shots`, once the rocket reaches the plane, zero `velocity.y` so it stays level.

- **Muzzle origin:** unchanged.
- **Flat heading:** `heading.y` is zeroed in the test, and the muzzle has no lateral offset, so the flat heading stays within the 0.995 dot check.
- **Same-height rivals:** a rocket that has already settled to the plane is the same shot the control cases already hit.
- **Homing and grenades:** untouched.
- **Wall occlusion:** the `_ray(origin, nozzle)` blocker check is unchanged. The descent is under a metre over 14 m, so it can't pass through anything the level shot wouldn't.

The split-step branch is long. If you want it smaller, drop it and clamp per tick instead. Add `if not is_nan(plane_y) and start.y <= plane_y: velocity.y = 0.0` (or `maxf(velocity.y, 0.0)`) before `var end := ...`. At 60 Hz the overshoot is under 2 m at 105 m/s with a slope near 0.05, which is negligible for the test. In that variant the 0.6 s test tick is one segment, so it would cross the plane partway through. That is why I wrote the split version above.

**Tunables.**
- **`SETTLE = 14`:** must be less than the test's 20 m so the rocket is level by the time it reaches the rival. For rivals closer than 14 m the rocket is still slightly above the plane.
