## Root causes
- **Flame:** `_quad` writes UV.y = 1 at the base and 0 at the tip (`city_roadside_fx.gd:41-44`). `roadside_fire.gdshader:27,36-41,44` treat UV.y as height. So the sway grows at the base, the width limit and "tip" fade are inverted, and the hot colour sits at the top. That gives the white inverted cone.
- **Fire AABB:** `build` makes `xf` with a yaw basis (`city_roadside_fx.gd:116`) and then calls `world_box(xf, mesh().custom_aabb)`. A yawed 4×H×4 box comes out larger than the axis-aligned box the layout reserves. The pool is symmetric and the smoke is world-anchored, so the yaw changes nothing visually. Dropping the basis rotation is safe.
- **Towers:** `TrackMaterials.environment` disables ambient and reflection (`track_materials.gd:45`). The canonical `StandardMaterial3D`s therefore only get direct light. Upper floors are outside the street lights, so they render black.

```diff
+## Tower-only local readability fill. The city environment has no ambient or reflection light, so upper floors outside streetlight reach render black.

+## a dim emission. Signs and lamps already emit, and the source library materials are never edited.
+const TOWER_FILL := {"glass_window": 0.32}
+const TOWER_FILL_DEFAULT := 0.22
+const TOWER_FILL_SKIP: Array[String] = ["sign_atlas", "lamp_glass"]

@@ available(), right after `var box := mesh.get_aabb()` guard passes (before `loaded[id] = raw`)

@@ (new function, before reset())
+static func _apply_tower_fill(mesh: ArrayMesh) -> void:
+	for surface in mesh.get_surface_count():
+		var source := mesh.surface_get_material(surface) as StandardMaterial3D
+		if source == null or source.resource_name in TOWER_FILL_SKIP or source.albedo_texture == null:
+			continue
+		if not tower_variants.has(source.resource_name):
+			var variant := source.duplicate() as StandardMaterial3D   # textures stay shared references
+			variant.emission_enabled = true
+			variant.emission_operator = BaseMaterial3D.EMISSION_OP_ADD
+			variant.emission = Color(0.8, 0.85, 1.0)
+			variant.emission_texture = source.albedo_texture
+			variant.emission_energy_multiplier = float(TOWER_FILL.get(source.resource_name, TOWER_FILL_DEFAULT))
+			variant.set_meta("tower_fill_of", source)
+			tower_variants[source.resource_name] = variant
+		mesh.surface_set_material(surface, tower_variants[source.resource_name])
@@ reset()
+	tower_variants = {}
```

`_load_mesh` returns a fresh ArrayMesh each time, so only the tower's own mesh changes. The canonical materials, GLBs and PNGs are untouched, and `resource_name` stays the same, so the `costs[...]["materials"]` names still match. The fill is emission through the existing albedo texture, so PBR normal and roughness are preserved. Because the texture is unshaded-bright times 0.22, it stays well below self-lit white, and the vertex wear still shows through the albedo term.
