**Root cause**

The only thing over budget is the extra `SwapPulse` mesh. `_triangles` (`blackjack_blueprint_tests.gd:264-272`) counts every `MeshInstance3D`, and the effects module adds `SwapPulse` as one. `MultiMesh` and particle nodes are not counted.

A `TorusMesh` has `rings * ring_segments * 2` triangles. That gives the following:

| Torus | Triangles | Optional total |
|---|---|---|
| 32x8 | 512 | 40455 |
| 24x4 | 192 | 40135 |
| 12x4 | 96 | 40039 |

The numbers are consistent: 40455 − 512 = 39943, 40135 − 192 = 39943, and 40039 − 96 = 39943.

So the existing vehicle with the optional supercharger is **39943 triangles. That leaves 57 triangles of headroom** under the 40000 limit.

The reductions can't work because the torus floor is 57. Any torus with 57 or fewer triangles has at most 3x9 or 4x7 segments, which would look like a bent triangle or polygon. The 12x4 version still cost 96, and no usable torus fits.

A 2-triangle quad brings the total to 39945, which passes with 55 to spare. The base budget is untouched.

**Fix** (`godot/scripts/vehicle_effects.gd`)

- The `QuadMesh` lies in the XY plane with its normal along +Z. The old torus axis was Y, and the X90 rotation turned it to Z. The quad is already in that orientation, so the X90 rotation must be removed. Keeping it would lay the ring flat.
- The torus ran from radius 0.46 to 0.5. A quad of size 1 has a half-extent of 0.5, so the shader uses `r = length(UV - 0.5) * 2.0` and draws the band from 0.92 to 1.0.
- The pulse material changes from `StandardMaterial3D` to `ShaderMaterial`. Its colour and alpha now go through a `tint` uniform instead of `albedo_color`. The tests only use `pulse_node()`, `global_position` and `basis.x.length()`, so they are unaffected. `basis.x.length()` still grows with the scale.

New file `godot/shaders/pulse_ring.gdshader`. Add it to git. If the lead prefers it code-native, use `Shader.new()` with `.code` set to the same string.

```glsl
shader_type spatial;
render_mode unshaded, blend_add, cull_disabled, depth_draw_never, shadows_disabled;

uniform vec4 tint : source_color = vec4(1.0);

void fragment() {
	float r = length(UV - vec2(0.5)) * 2.0;
	float ring = smoothstep(0.90, 0.93, r) * (1.0 - smoothstep(0.99, 1.0, r));
	ALBEDO = tint.rgb;
	ALPHA = tint.a * ring;
}
```

If `depth_draw_never` or `shadows_disabled` raises a compile error in this Godot version, drop it. `cast_shadow` is already off on the node.
