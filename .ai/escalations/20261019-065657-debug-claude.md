**Root cause (probable, not certain):** `VehicleAudio` holds `_engine_playback` (a `RefCounted`) in a script member (`vehicle_audio.gd:11`, assigned at `:47`). Nothing ever releases it. The only releases are indirect ones that run when the node is freed.

In `race_visual_qa.gd:24-26` the terrain path calls `quit()` straight after the last capture. The race and `VehicleAudio` are still in the tree, so teardown happens during engine finalization. By then PulseAudio is already terminated (log 511) and `AudioServer` is shutting down.

The full race path (`:84-89`) changes to garage first. That frees the race while the tree is still live, so the player stops and the playback is released normally. The log has no Node leaks, so the nodes are freed. The extra reference is the playback itself, which an engine-side reference or the script member still holds when `ObjectDB` is checked.

I did not run anything, so this is inferred from the log and the code. Neither file shows who holds the last reference.

**Fix (two parts, both small).**

Make `VehicleAudio` release its own handle on exit. This is correct on its own, because it is robust to any shutdown order:

```diff
--- a/godot/scripts/vehicle_audio.gd
+++ b/godot/scripts/vehicle_audio.gd
@@ func _process(delta: float) -> void:
+func _exit_tree() -> void:
+   if _engine_player != null:
+       _engine_player.stop()
+   _engine_playback = null
+
+
 func _on_swapped(_record: Dictionary) -> void:
```

In the fixture, free the race before quitting, as the full race path does. Use whatever variable `race_visual_qa.gd` already holds for the race (I haven't read its definition):

```diff
        await _terrain_captures()
+       _race.queue_free()   # use the fixture's actual race node reference
+       for _i in 3:
+           await get_tree().process_frame
        get_tree().quit(1 if _fail else 0)
```

`queue_free` plus a couple of frames lets `_exit_tree` run and the audio server drop its playback while it is still alive.
