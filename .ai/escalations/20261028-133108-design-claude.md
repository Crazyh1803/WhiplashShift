## Recommendation: keep one forward "geometry" course, and build a separate reversed "race" course for driving

**1. Course reversal (`CourseDefinition` / `CourseCatalog`)**

```gdscript
# course_definition.gd
var reversed := false
var geometry_source: CourseDefinition = null   # null means self
func geometry() -> CourseDefinition: return geometry_source if geometry_source else self
func with_laps(laps: int) -> CourseDefinition   # 0 = keep default_laps; else clampi(1, 99)

# course_catalog.gd
static func build_course(id: String, reverse := false, laps := 0) -> CourseDefinition
static func reverse_points(f: Array) -> Array
```

Reversal maps every point and edge exactly. Each point `i` describes the edge from `i` to `i+1` (`dist`, `s`, `relief`; see `track_data.gd:78-86`). With `n = f.size()`, `v = (n-k)%n` and `e = (n-k-1)%n`:

```
r[k] = {pos: f[v].pos, dir: -f[v].dir, w: f[v].w,
        s: f[e].s, dist: f[e].dist, relief: f[e].relief.duplicate(true) if present}
```

This keeps `r[0].pos == f[0].pos`. It produces `-dir` exactly, because the tangent is `(next-prev)`, and `dist` exactly, because `r[k]→r[k+1]` is forward edge `e`. Copy `relief` unchanged. **Do not swap rise and fall**: `track_relief.gd:68` rejects `fall < rise`, so a swapped 14/16 ramp fails validation.

**The geometry source is required.** Build the road, rails and all scenery from `course.geometry()`. Build progress, the CPU, cues, approach boards, guidance chevrons, the finish line and the HUD minimap from the race course. The reasons:
- `TrackBuilder.build` seeds relief by run index from `TrackRelief.partition` (`track_relief.gd:137-157`). Partitioning does not wrap, so a reversed order changes run indices and the split at index 0. That would move boulders.
- `CityScenery` samples by cumulative distance from point 0 and puts things to the side using `dir.cross(UP)` (`city_scenery.gd:78-80,143-146`). `TrackScenery` uses fixed indices 30, 85 and 155 (`track_scenery.gd:61,87,96`). Building from reversed points would mirror or move the whole city.
- In `proving_ground.gd:79-81`, pass `course.geometry().points` to `TrackBuilder.build` and `build_guard_rails`. Split `build_scenery` so `build_guidance` alone takes the race course.

**Start and grid.** `_grid_indices = [n-14, n-4, n-9]` (`proving_ground.gd:109`). In reverse these land on forward points 14, 4 and 9, which are not checked. Add:

```gdscript
static func grid_clear(points: Array, start: int, behind := 14) -> bool
# every edge in [start-behind, start+2] is TARMAC, has no active relief profile,
# and the heading spread is <= 8 degrees
```

Apply it **only when reversed**. Search outward from index 0 for the nearest start that passes, then rotate (`slice(k) + slice(0,k)`) and run `configure()` again. Never let index 0 fall inside a relief run: splitting a ramp run makes the course fail validation (`track_relief.gd:192`). Forward courses are never rotated, which keeps the Split Shift golden unchanged. Add a test that every forward course passes `grid_clear(…, 0)`.

**Known gap:** `CityScenery._crown` places itself relative to the forward `points[0]` (`city_scenery.gd:322`). That is fine for a landmark, but don't add "start gantry" dressing tied to the forward start.

**Laps:** `RaceDirector` and the HUD read `course.default_laps`, so `with_laps` overriding it on the built copy is enough. `laps = 0` (the default) keeps the three-lap behaviour for the existing tests.

**2. `SeasonDefinition` and `SeasonLibrary` (RefCounted, not Resource)**

```gdscript
const FORMAT := "whiplash-season"; const VERSION := 1
const MAX_RACES := 30; const MAX_NAME := 40; const MAX_BYTES := 16384
var name: String; var races: Array[Dictionary]   # {course_id, laps:int, reverse:bool}
static func from_dict(d: Variant) -> Dictionary  # {ok, season, errors}; never partial
func to_dict() -> Dictionary
static func encode_share(s) -> String            # "WS1." + base64url(json) + "." + sha256[0..8]
static func decode_share(text: String) -> Dictionary
```

`SeasonLibrary` (`user://seasons/<slug>.json`):
- `list() -> Array[Dictionary]` reads at most 64 files and skips invalid ones.
- `save(season) -> Error` writes `.tmp`, then `DirAccess.rename`.
- `load(slug)`, `remove(slug)`, `season_one() -> {races, plan: [{title, course_id_or_empty, available}]}`.

Security pitfalls, all mandatory:
- Use **JSON only.** Never `ResourceLoader.load`, `str_to_var`, `bytes_to_var` or `ConfigFile.parse` on imported text: they can build Objects or Resources with scripts attached.
- Check size before parsing.
- JSON numbers arrive as floats, so require `laps == floor(laps)` within 1-99.
- Reject unknown keys, unknown `course_id` values (`CourseCatalog.IDS` only), a wrong format or version, and non-bool `reverse`.
- Strip control characters from `name`. Make the slug with `[a-z0-9-]`, at most 32 characters.
- Validate everything into a new object, then save. On any error, return the error and leave the library untouched.

**3. Championship (`SeasonRun`, held by `GameSession.season`; null means single race)**

```gdscript
const POINTS := [10, 6, 3]
var definition; var round := 0
var entrants: Array[Dictionary]       # slot 0 = player; {callsign, vehicle_id}
var points: PackedInt32Array; var wins: PackedInt32Array
var pending: Array[int] = []          # standings of the current round; overwritten on retry
func race_options() -> Dictionary     # {course_id, laps, reverse}
func set_pending(order: Array[int])   # call on every RESULTS
func commit() -> bool                 # scores once, round += 1; false if pending is empty
func is_complete() -> bool
func table() -> Array[int]            # points desc, wins desc, slot asc
```

Committing points only when the player presses **Continue** is what makes retries safe from double scoring.

Pitfall: `restart_race` and `_build_cpu_drivers` redraw callsigns and rosters (`proving_ground.gd:225,129-130`). When `GameSession.season` is set, take `cpu_callsigns` and the roster from `season.entrants` and skip `_draw_callsigns()`. Otherwise the entrant names in the standings won't match from race to race.

**4. Results UI (small change to `hud.gd`)**
- Add `signal continue_requested`, plus `var continue_caption := ""` and `var season_lines := PackedStringArray()`.
- In `_build_results`, add a third `ContinueButton` that is hidden when the caption is empty.
- In the RESULTS branch (`hud.gd:280-288`), append `season_lines` (marked provisional) after the race times.
- `proving_ground` sets the caption to "NEXT RACE" or "FINAL STANDINGS". On press it calls `commit()`, then either `reload_current_scene()` with the new options, or shows final lines with the caption cleared.
- `_return_to_menu` should point to the new menu scene.

**Main tradeoff:** races use two course objects, so tests must cover both: geometry identical to forward, and race metadata reversed. **The alternative:** bake reversed variants into the data files. That is simpler at runtime but doubles the authoring and loses the "world doesn't move" guarantee.
