## Integration decisions
The block is created before legacy scenery so explicit reservation bounds prevent old walls crossing sidewalks. `_Kit` preserves RNG calls but rejects near geometry in those bounds; skyline/crown code and distant silhouettes are unchanged. CityDistrict consumes the reservation explicitly and ignores block batch meshes during its old obstacle scan. Relay slots move past the block only when it is present. Missing new resources produce the complete old district with no reservations.

Ground extents run from rail+3.6 to rail+63m. Raised modular slabs occur at the detailed building frontages; inexpensive continuous paving fills the other stretches, limiting repetition cost. Two service streets at s75/189 have curb breaks and sloping entrances. Existing shutter_workshop/ribbed_stack models fill selected vacant lots only if real solid bounds and the same190k total block budget permit. All four detailed buildings and eight street categories are required; optional infill never displaces them. Source authored GLBs remain unchanged.
